# note 記事の書き方

## 構成
1. **冒頭（3〜5行）**: 読者の悩みをそのまま言語化する →「この記事で何が手に入るか」を約束する
2. **結論を先に**: 一番伝えたいことを最初の見出しで言い切る
3. **本文**: 見出しごとに「主張 → 理由 → 具体例（手順・画面・数字）」
4. **まとめ**: 3行で要点を振り返る
5. **次の行動**: 読者が今日やれることを1つだけ示す

## 文体
- です・ます調。1文は60字以内を目安
- 専門用語は初出で一言説明する
- 「誰でも」「絶対」などの断定は避ける

## チェックリスト
- [ ] タイトルに「誰向け」と「得られるもの」が入っている
- [ ] 冒頭で悩みに触れている
- [ ] 具体的な手順か事例が最低3つある
- [ ] 出典のない数字がない
