# ショート動画台本のルール

## 尺と構成（60〜90秒想定）
| 区間 | 秒数 | 内容 |
|---|---|---|
| フック | 0〜3秒 | 結論 or 強い一言（例:「全員この機能7つ入れろ」） |
| 共感 | 3〜8秒 | 視聴者の悩み・あるある |
| 本編 | 8〜70秒 | ①②③…と番号付きで1項目10秒前後 |
| まとめ | 〜80秒 | 「つまり〜」で一言にまとめる |
| CTA | 最後 | 保存・フォロー・DM 等の行動を1つ |

## 書式
各カットを次の形式で書く:

```
[カット番号] 秒数
テロップ: （画面に出す文字。15字以内）
ナレーション: （話す内容）
画面: （映す素材・操作画面）
```

## ルール
- テロップは1カット1メッセージ、15字以内
- 番号（①②③）で進行を見せる
- 専門用語にはその場で一言の言い換えをつける
